# BlackBox para PC — instaladores

Aqui ficam só os **instaladores** do BlackBox para PC, o aplicativo da [BaseFly](https://basefly.io) que mantém
pastas do BlackBox sincronizadas com o computador. O código é privado e não está neste repositório.

- **Instalar:** baixe o [instalador mais recente](https://github.com/basefly-io/blackbox-pc-instaladores/releases/latest/download/BlackBox_x64-setup.exe).
  Depois de instalado, o aplicativo se atualiza sozinho.
- **Segurança:** cada versão é assinada pela chave da BaseFly. O aplicativo só instala uma atualização se a assinatura
  conferir, então um arquivo trocado aqui seria recusado.
- **Para conectar:** é preciso uma conta no BlackBox de uma empresa cliente da BaseFly.
